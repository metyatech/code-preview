# Security Policy

## Supported Versions

The following versions of `@metyatech/code-preview` are currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| >= 0.2.x | :white_check_mark: |
| < 0.2.x | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it by opening an issue on the GitHub repository. For sensitive issues, please contact the maintainers directly.
